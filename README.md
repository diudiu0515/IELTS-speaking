# IELTS Speaking Stories

个人雅思口语故事库：6 个母故事、24 个串题切口，包含英文讲述、换题改写方法、关键词提纲、表达积累和 Part 3 延伸。

## 启用 GitHub Pages

网站为纯静态 HTML/CSS/JavaScript，无须安装依赖、构建或 API key。

1. 打开仓库 Settings → Pages。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 **main**，文件夹选择 **/(root)**，点击 Save。
4. 等待 Actions 中的 Pages 发布任务成功，以 Settings → Pages 显示的网址为准。

预期发布地址：https://diudiu0515.github.io/IELTS-speaking/

上述是预期地址；提交代码不代表已经开启 Pages。GitHub Pages 上的故事内容将公开可访问。

## 编辑内容

- `stories.js`：6 个故事、24 道题及英文讲述、表达积累和 Part 3 内容。
- `app.js`：选故事、选题和完整讲述/关键词提纲切换。
- `style.css`：桌面与手机样式。
- `index.html`：页面结构。

英文讲述基于已分享的经历整理，感受与反思可按实际修改。题目为练习示例，非当季完整题库。文字本身不保证雅思分数。
